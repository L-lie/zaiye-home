API 配置教程

第一次设置也可以跟着完成

先从 Gemini 开始

API Key 可以理解为服务商发给你的专用访问凭证。Prompt Vault 用它连接你选择的 AI 服务；Key 需要由你本人在对应服务商处申请。

Gemini DeepSeek Groq OpenAI 自定义兼容接口

设置前先知道

  • 部分服务商只在创建时完整显示一次 API Key；创建后请立即复制，并存入可信的密码管理器。
  • 不要公开、截图分享或发送自己的 API Key。
  • 不要把 Key 保存成 Prompt 条目；“设为隐私 Prompt”目前只隐藏界面显示，并不会把正文排除在导出、备份或同步之外。
  • 如果 Key 遗失或怀疑已经泄露，请在服务商控制台撤销旧 Key，再新建一个。
  • 不同服务可能产生费用；额度、价格和可用模型以服务商当前说明为准。
  • 填写在“AI 设置”里的 Key 才会单独保存在当前浏览器，不会进入 Prompt 的导出、备份或同步内容。
Gemini推荐先设置 展开步骤
  1. 注册或登录 Google 账号。
  2. 打开 Gemini 官方 API Key 页面。
  3. 按页面提示创建 API Key，并立即复制到可信的密码管理器；部分 Key 在页面关闭后无法再次完整查看。
  4. 回到 Prompt Vault，打开“AI 设置”。
  5. 服务商选择“Gemini”，粘贴刚复制的 Key。
  6. 点击保存，完成配置。

如果 Gemini API 页面打不开，可尝试把科学上网／网络代理节点切换到美国后重新打开。

DeepSeek使用 DeepSeek 官方服务 展开步骤
  1. 注册或登录 DeepSeek 开放平台。
  2. 前往 DeepSeek 官方 API Keys 页面创建并复制 Key。
  3. 回到 Prompt Vault 的“AI 设置”，选择“DeepSeek”。
  4. 粘贴 Key 后保存。
Groq使用 Groq 官方服务 展开步骤
  1. 注册或登录 Groq Console。
  2. 前往 Groq 官方 API Keys 页面创建并复制 Key。
  3. 回到 Prompt Vault 的“AI 设置”，选择“Groq”。
  4. 粘贴 Key 后保存。
OpenAI使用 OpenAI 官方服务 展开步骤
  1. 注册或登录 OpenAI Platform。
  2. 前往 OpenAI 官方 API Keys 页面创建并复制 Key。
  3. 回到 Prompt Vault 的“AI 设置”，选择“OpenAI”。
  4. 粘贴 Key 后保存。
自定义兼容接口连接其他兼容服务 展开步骤

请向你实际使用的服务商索取 endpoint、model 和 key，再填入 Prompt Vault 对应位置。自定义接口没有统一的申请入口，不要混用其他服务商的地址或 Key。
