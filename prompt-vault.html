API 配置教程

第一次设置也可以跟着完成

先从 Gemini 开始

API Key 可以理解为服务商发给你的专用访问凭证。Prompt Vault 用它连接你选择的 AI 服务；Key 需要由你本人在对应服务商处申请。

Gemini DeepSeek Groq OpenAI 自定义兼容接口

设置前先知道

  • 部分服务商只在创建时完整显示一次 API Key；创建后请立即复制，并存入可信的密码管理器。
  • 不要公开、截图分享或发送自己的 API Key。
  • 如果你把 Key 保存成 Prompt 条目，请将它“设为隐私 Prompt”。隐私 Prompt 会自动从“导出全部”“导出当前筛选”和“导出选择”中排除，不会进入分享用的导出 JSON。
  • 隐私 Prompt 仍会进入备份和同步，方便恢复数据或跨设备使用。因此备份与同步文件仍可能包含你的 Key，属于敏感数据，请勿发送给别人。
  • 如果 Key 遗失或怀疑已经泄露，请在服务商控制台撤销旧 Key，再新建一个。
  • 不同服务可能产生费用；额度、价格和可用模型以服务商当前说明为准。
  • 填写在“AI 设置”里的 Key 才会单独保存在当前浏览器，不会进入 Prompt 的导出、备份或同步内容。
Gemini推荐先设置 · 有免费层，也可付费 展开步骤
费用先说清楚

Gemini API 目前有免费层，但只适用于部分模型并受额度限制；需要更高额度时可以为项目启用付费。免费额度、价格和可用模型可能调整，请以 Gemini 官方价格页和 计费说明为准。

申请 Gemini API Key

  1. 登录账号：先登录你的 Google 账号；第一次进入 Google AI Studio 时，按页面提示同意使用条款。
  2. 进入 Key 页面：打开 Gemini 官方 API Key 页面。
  3. 找到或新建 Key：新账号可能已经自动建立默认项目和 Key，直接点复制即可。没有 Key 时，点击页面里的“Create API key”；如果看不到项目，先按提示导入或创建 Google Cloud 项目。
  4. 马上妥善保存：复制完整 Key，立即存入可信的密码管理器。部分服务商的 Key 只在创建时完整显示一次，关掉页面后可能无法再次查看。

填入 Prompt Vault

  1. 打开设置：回到 Prompt Vault，点击右上角太阳／月亮图标打开“主题设置”，再点击“AI 设置”。
  2. 选择服务：在“AI 服务设置”中选择“使用自己的 API”，服务商选择“Gemini”。也可以点击“使用 Gemini 免费额度”快速选中该预设。
  3. 粘贴并保存：官方 API 地址和模型会自动填写；只需把 Key 粘贴进“API Key”，再点“保存”。看到“AI 设置已保存。”就表示设置已经写入当前浏览器。
  4. 做一次测试：打开 AI 助手或图析，发送一条简单请求。能正常返回内容，就表示配置完成；提示额度不足时，到 Google AI Studio 的 Usage 查看使用量或计费状态。

页面打不开：请把科学上网／网络代理节点切换到美国，再重新打开 Gemini API 页面。如果仍无法创建 Key，通常需要检查当前 Google 账号、项目权限或所在地区是否可用。

DeepSeek按量计费 · 从账户余额扣费 展开步骤
费用先说清楚

DeepSeek API 按实际用量计费，费用从充值余额或服务商发放的余额中扣除；不能把赠送余额当作长期免费保证。具体单价以 DeepSeek 官方价格页为准。

申请 DeepSeek API Key

  1. 登录平台：注册或登录 DeepSeek 开放平台。这里是 API 平台，不是普通的 DeepSeek 对话页面。
  2. 新建 Key：进入 DeepSeek 官方 API Keys 页面，找到创建／新建 API Key 的按钮，可取名为“Prompt Vault”。
  3. 复制并保存：创建后立即复制完整 Key，优先存入可信的密码管理器，不要截图或公开。如果也保存成 Prompt 条目，请设为隐私；它不会进入导出 JSON，但仍会进入备份和同步，因此备份文件不要外传。
  4. 检查余额：在开放平台查看当前余额。没有可用余额时，即使 Key 正确也可能无法调用。

填入 Prompt Vault

  1. 打开设置：点击 Prompt Vault 右上角“主题设置”图标，再进入“AI 设置”。
  2. 选择服务：选择“使用自己的 API”，服务商选“DeepSeek”；官方地址和模型会自动填写。
  3. 保存并测试：粘贴 Key，点“保存”，看到“AI 设置已保存。”后，到 AI 助手或图析发送一条简单请求。

报错怎么看：401 通常表示 Key 错误、失效或已撤销；402 表示余额不足，需要在 DeepSeek 平台充值或等待可用余额；429 表示请求过快，请稍后再试。

Groq有免费层 · 付费层按量计费 展开步骤
费用先说清楚

Groq 目前提供受速率和用量限制的免费层；需要更高限制时，可添加付款方式升级到按量计费的 Developer 层。免费限制和付费规则可能变化，请查看 Groq 官方计费说明。

申请 Groq API Key

  1. 登录控制台：注册或登录 Groq Console。
  2. 确认项目：如果控制台要求选择项目，可在左上角“Organization / Projects”中选择现有项目或创建一个新项目。API Key 会归属于当前项目。
  3. 新建 Key：打开 Groq 官方 API Keys 页面，创建一个新 Key，可取名为“Prompt Vault”。
  4. 复制并保存：立即复制完整 Key 并存入可信的密码管理器；页面关闭后如果找不回完整内容，就撤销旧 Key 再新建。

填入 Prompt Vault

  1. 打开设置：点击 Prompt Vault 右上角“主题设置”图标，再进入“AI 设置”。
  2. 选择预设：选择“使用自己的 API”，再根据想用的模型选择“Groq Qwen”或“Groq GPT-OSS”；官方地址和模型会自动填写。
  3. 保存并测试：粘贴 Key，保存后到 AI 助手或图析发送一条简单请求。免费层提示达到速率／额度限制时，可以稍后再试，或按需查看付费升级。
OpenAIAPI 单独计费 · 不包含在 ChatGPT 订阅里 展开步骤
费用先说清楚

OpenAI API 与 ChatGPT 是两套独立的计费系统。即使已经订阅 ChatGPT Plus／Pro，也不代表 API 已有额度；API 通常需要在 OpenAI Platform 单独设置付款方式或购买额度。请查看 OpenAI 官方计费说明。

申请 OpenAI API Key

  1. 登录 API 平台：登录 OpenAI Platform；它与平时使用的 ChatGPT 对话页面不同。
  2. 确认项目：在平台中选择准备给 Prompt Vault 使用的项目。个人第一次使用时，使用默认项目即可。
  3. 创建 Key：进入 OpenAI 官方 API Keys 页面，点击“Create new secret key”，可取名为“Prompt Vault”。小白用户可先使用默认权限；如果自行改成 Restricted，需要确保相关模型接口有调用权限。
  4. 只显示一次：创建后马上复制完整 Secret Key 并存入可信的密码管理器。OpenAI 不会再次显示这段完整 Key；遗失后只能撤销旧 Key 并新建。
  5. 检查 API 计费：到 OpenAI Platform 的 Billing 页面确认 API 账户是否已有可用额度或付款方式，不要把 ChatGPT 订阅状态当成 API 余额。

填入 Prompt Vault

  1. 打开设置：点击 Prompt Vault 右上角“主题设置”图标，再进入“AI 设置”。
  2. 选择服务：选择“使用自己的 API”，服务商选“OpenAI”；官方地址和模型会自动填写。
  3. 保存并测试：粘贴 Key，保存后到 AI 助手或图析发送一条简单请求。提示 Key 无效时重新复制或新建；提示额度／计费问题时检查 OpenAI Platform 的 API Billing。
自定义兼容接口费用和额度由实际服务商决定 展开步骤
费用先说清楚

自定义兼容接口没有统一的免费或付费规则，费用、额度、退款和模型可用性都由你实际选择的服务商决定。使用前请先阅读该服务商自己的价格与隐私说明。

  1. 先向服务商确认三项资料：endpoint（API 地址）、model（模型名称）和 key（API Key）。三项必须来自同一家服务商，不能混用。
  2. 打开设置：点击 Prompt Vault 右上角“主题设置”图标，再进入“AI 设置”，选择“使用自己的 API”和“自定义 OpenAI-compatible”。
  3. 逐项填写：把服务商提供的 API 地址、模型名称和 Key 填入对应输入框，再点击“保存”。
  4. 做一次测试：到 AI 助手或图析发送一条简单请求。失败时，把错误提示和所填的 endpoint／model 交给该服务商核对，但不要把完整 Key 发给任何人。

这里没有一个适用于所有兼容接口的申请链接。若服务商只给了聊天网址，没有提供 API 文档、endpoint、model 和 key，就不能直接当作兼容接口使用。
