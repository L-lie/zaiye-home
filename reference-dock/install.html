把 Reference Dock
装进 Photoshop

先选择你能使用的安装方式。可以使用 Creative Cloud 安装器时下载 CCX；安装器不可用时，通过 UXP Developer Tool 加载开发版文件夹。

开始安装 遇到问题

安装前确认

Photoshop
25.0 或更高版本
插件版本
Reference Dock 1.0.0
安装文件
CCX 或开发版 ZIP

修改版 Photoshop 的 UXP 支持情况不固定，无法保证每个版本都能加载。

选择安装方式

你的电脑适合哪一种？

两种方式安装的是同一个插件。优先尝试 CCX；只有常规安装器不可用时，再使用本地加载。

A

常规安装

双击 CCX 安装

适合可以正常打开 Creative Cloud Desktop 安装确认窗口的电脑。

  1. 下载 Reference-Dock-v1.0.0.ccx。
  2. 退出 Photoshop，双击 CCX 文件。
  3. 在 Creative Cloud 确认窗口选择“本地安装”。
  4. 重新打开 Photoshop，在“增效工具”中打开 Reference Dock。
下载 CCX 安装包
B

本地加载

加载开发版文件夹

适合 CCX 安装器不可用，但电脑已经可以运行 Adobe UXP Developer Tool 的情况。

  1. 下载开发版 ZIP，并完整解压到固定文件夹。
  2. 打开 Photoshop 和 UXP Developer Tool。
  3. 点击 Add Plugin，选择解压目录根部的 manifest.json。
  4. 点击 Load，再从 Photoshop“增效工具”中打开 Reference Dock。
下载开发版 ZIP

安装完成后

打开面板，停靠到工作区

  1. 打开 Reference Dock 在 Photoshop 顶部菜单找到“增效工具”或 Plugins，再选择 Reference Dock。
  2. 停靠面板 拖动面板标题栏，把它放到 Photoshop 工作区左侧或右侧。
  3. 导入第一张参考图 点击面板工具栏中的导入按钮，选择 PNG、JPG、JPEG 或 WebP。

开发版加载后不要移动文件夹

UXP Developer Tool 会记住当前目录。移动、改名或删除解压后的插件文件夹，会导致下次无法加载。

安装排错

没有出现面板，先检查这里

双击 CCX 没有任何反应

CCX 文件没有正确关联到 Creative Cloud 安装器。可以改用开发版 ZIP；如果希望继续使用 CCX，需要修复或重新安装官方 Creative Cloud Desktop。

UXP Developer Tool 提示 Manifest Validation Failed

确认选择的是解压目录根部的 manifest.json，并且 assets、icons、index.html 等文件仍在同一目录结构中。

Load 失败或按钮变红

先确认 Photoshop 已经启动，版本不低于 25.0；再打开错误详情。如果插件目录被移动，请从 Developer Tool 中移除旧记录后重新 Add Plugin。

加载成功，但 Photoshop 里找不到面板

重新打开 Photoshop，然后在“增效工具”或 Plugins 菜单中查找 Reference Dock。面板可能以浮动窗口出现在屏幕边缘。

下次打开时参考图消失

原始图片被移动、删除，或系统撤销了文件访问权限。重新导入图片即可；插件不会复制或上传你的原图。

安全下载

只从官网获取安装包

两个下载包包含同一版本。开发版 ZIP 用于本地加载，CCX 用于常规安装。
