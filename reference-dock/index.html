常见问题

Reference Dock 会遮挡 Photoshop 画布吗？

它是可停靠、可调整尺寸的 Photoshop 原生面板，可以放在工作区左侧或右侧。

可以直接从参考图吸取颜色吗？

可以。点击参考图中的像素即可更新 Photoshop 前景色，并显示 HEX 与 RGB 数值。

可以把 Photoshop 图层放进参考板吗？

可以。当前选中图层会生成参考快照加入画布，但不会与原图层保持实时链接。

Creative Cloud 安装器不可用怎么办？

下载开发版 ZIP，完整解压后，通过 UXP Developer Tool 选择根目录的 manifest.json 加载。具体步骤见安装教程。

它会取代 PureRef 吗？

Reference Dock 专注于 Photoshop 内部的参考工作流，不会覆盖 PureRef 的全部高级功能。
